# SAMAI Qualified Leads — release candidate v12

Исходники непрерывной полноэкранной WebGL-страницы для публикации на `/test/`. Production-сборка создаётся из этой папки, затем упаковывается `tools/build_v12.py` и проверяется `tools/v12_gate.py` в Chromium, Firefox и WebKit.

## Что реализовано

- одна непрерывная полноэкранная WebGL-сцена вместо набора независимых секций;
- путь `отбор → базовые критерии → критерии клиента → передача → правила работы → результат → тест`;
- четыре базовых критерия не ограничивают настройку: финальные условия задаёт заказчик;
- карточка квалифицированного лида показывает контекст для первого звонка;
- тест из 10 лидов появляется после объяснения основного продукта;
- остановка скролла мягко доводится до законченных смысловых кадров;
- фирменный знак SAMAI и название текущего этапа остаются доступными во время всей сцены;
- ключевые карточки и статусы собраны в чётком HTML-слое поверх WebGL, поэтому текст не размывается;
- передача лида визуально связана с проверкой `4/4`, подтверждённым интересом и статусом для отдела продаж;
- протокол передачи показывает подтверждённые правила из продуктовой таблицы: звонок с записью, эксклюзивную передачу одному агентству, 24 часа на приёмку и замену подтверждённого брака до 3 дней;
- proof-сцена использует только собственные кейсы из Notion: «Ключ» (8 бронирований из канала квалифицированных лидов в августе 2026, средний бюджет покупателя 18,54 млн ₽) и Room (11 месяцев сотрудничества, масштабирование после теста до 100 лидов);
- оговорка `бронь ≠ закрытая сделка` показана непосредственно в кейсе; спорный ROMI ×24 и когортная связка `70 лидов → 8 броней` намеренно не используются;
- форма запрашивает только контакт, географию, сегмент и стартовый объём;
- перед полями формы показан ожидаемый путь: критерии → правила замены → тест из 10 лидов;
- форма работает через существующий allowlisted endpoint, требует согласие, поддерживает idempotency и безопасный retry;
- аналитика не отправляет персональные данные;
- desktop/mobile и режим уменьшенного движения.

## Локальный запуск

```text
pnpm install --frozen-lockfile
pnpm dev
```

На localhost transport формы остаётся закрытым, если тест явно не включает перехватчик. Release gate перехватывает все POST-запросы, поэтому не создаёт production-данные и не отправляет Telegram-сообщения. Сцена собрана кодом на Three.js без внешних 3D-моделей и сетевых ассетов.
