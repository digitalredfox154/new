# Шаблон доказательной базы кейса SAMAI

Кейс попадает на сайт только после проверки источников и разрешения клиента. Один заполненный документ — один кейс.

## 1. Право на публикацию

- Клиент и контакт согласующего:
- Можно назвать компанию: да / нет
- Можно использовать логотип: да / нет
- Можно назвать период работы: да / нет
- Можно публиковать абсолютные цифры: да / нет
- Можно публиковать относительные изменения: да / нет
- Дата и источник письменного согласия:

Если согласия нет, используем обезличенное описание без деталей, по которым можно определить клиента.

## 5. Проверка формулировок

- Не обещает ли текст такой же результат другим компаниям?
- Совпадают ли период, база сравнения и единицы измерения?
- Отделены ли обращения, встречи, сделки и выручка?
- Указана ли роль клиента в результате?
- Можно ли подтвердить каждую опубликованную цифру исходным материалом?
